# Design: визуальная система Studio 313

## Назначение

Этот документ описывает визуальный язык сайта Studio 313: цвета, шрифты, CSS-переменные, сетку, компоненты, анимации и адаптив. Его задача - быть источником правды для переноса дизайна в Nuxt 4 и для последующих правок интерфейса.

## Характер бренда

Сайт должен ощущаться как премиальная студия подкастов, интервью, видеосъемки и продакшна.

Ключевые ощущения:

- современно;
- дорого;
- технологично;
- студийно;
- динамично;
- с акцентом на фото, видео, звук и движение.

Интерфейс не должен выглядеть как обычная визитка. Основной визуальный прием - крупная editorial-типографика, сильный синий акцент, много воздуха, крупные медиа и плавные интеракции.

## Цветовая система

### Базовая палитра

```css
:root {
  --color-accent: #0069fe;
  --color-accent-600: #0051c6;
  --color-accent-700: #004fc4;
  --color-accent-800: #003f9d;

  --color-ink: #07101f;
  --color-text: #1b2433;
  --color-muted: rgba(7, 16, 31, 0.62);
  --color-soft: rgba(7, 16, 31, 0.08);

  --color-white: #ffffff;
  --color-page: #f7f9fc;
  --color-panel: rgba(255, 255, 255, 0.92);

  --shadow-accent: 0 20px 44px rgba(0, 105, 254, 0.24);
  --shadow-panel: 0 24px 70px rgba(7, 16, 31, 0.12);
}
```

### Роли цветов

- `#0069fe` - главный брендовый акцент, CTA, активные состояния, маркеры, SVG-иконки.
- `#0051c6`, `#004fc4`, `#003f9d` - темные синие оттенки для градиентов, сайдбара, mobile dock и hover-состояний.
- `#07101f` - основной темный цвет для заголовков и важных текстов.
- Белый - основной фон карточек, модалок, сайдбар-кнопки записи.
- Светло-серый/почти белый - общий фон публичных секций.

### Градиенты

Основной синий градиент:

```css
background: linear-gradient(145deg, #0062ee 0%, #004fc4 34%, #0077ff 68%, #003f9d 100%);
```

CTA-градиент:

```css
background: linear-gradient(135deg, #0069fe, #0051c6);
```

Градиенты используются функционально:

- сайдбар;
- mobile dock;
- основные CTA;
- промо-блоки;
- статистика;
- активные элементы.

Не использовать синие градиенты как случайную декоративную заливку для каждого блока. Синий должен оставаться акцентом и навигационной силой.

## Типографика

### Шрифты

```css
@font-face {
  font-family: 'TT Firs ExtraBold';
  src: url('/fonts/TTFirs-ExtraBold.woff') format('woff');
  font-weight: 800;
}

body {
  font-family: Inter, system-ui, sans-serif;
}

h1,
h2,
h3,
h4,
.nav-link,
.brand-text,
.display {
  font-family: 'TT Firs ExtraBold', Inter, sans-serif;
}
```

### Роли шрифтов

- `TT Firs ExtraBold` - заголовки, меню, крупные цифры, цены, CTA-акценты.
- `Inter` - основной текст, формы, подписи, админка, служебные элементы.

### Принципы набора

- Заголовки крупные, плотные, uppercase там, где нужен брендовый эффект.
- Основной текст спокойный, хорошо читаемый, без декоративности.
- В компактных UI-панелях не использовать hero-размеры.
- Letter spacing для обычного текста - `0`.
- Для кнопок допустим небольшой uppercase tracking: около `0.07em`.

### Рекомендуемая шкала

```css
:root {
  --font-body: Inter, system-ui, sans-serif;
  --font-display: 'TT Firs ExtraBold', Inter, sans-serif;

  --text-xs: 12px;
  --text-sm: 14px;
  --text-md: 16px;
  --text-lg: 18px;
  --text-xl: 22px;

  --display-sm: clamp(30px, 3vw, 54px);
  --display-md: clamp(42px, 5vw, 82px);
  --display-lg: clamp(56px, 8vw, 132px);
}
```

## Сетка и layout

### Desktop

Основной desktop-сценарий - горизонтальная интерактивная лента с фиксированным левым сайдбаром.

```css
:root {
  --sidebar-width: 320px;
  --sidebar-collapsed-width: 112px;
  --page-padding: clamp(22px, 3vw, 56px);
  --section-gap: clamp(22px, 3vw, 44px);
}
```

Правила:

- сайдбар фиксирован слева;
- рабочая область занимает `100vh`;
- секции листаются горизонтально на desktop;
- активная секция подсвечивается в навигации;
- контент внутри секции должен иметь стабильные отступы и не прилипать к краям.

### Mobile

На мобильных горизонтальный сценарий можно заменить вертикальным.

Правила:

- нижняя mobile dock-навигация;
- меню открывается полноэкранным слоем;
- секции читаются вертикально;
- анимации упрощаются;
- контент и кнопки не должны перекрывать нижний dock.

## Основные компоненты

### Sidebar

Сайдбар - главный брендовый и навигационный элемент.

Свойства:

- синий динамический градиент;
- логотип сверху;
- навигация по секциям в центре;
- контакты, соцсети и CTA снизу;
- режим collapsed с иконками;
- плавное сворачивание.

Активный nav item:

- светлая/полупрозрачная подложка;
- иконка или текст визуально сильнее;
- hover с легким подъемом.

### Mobile Dock

Нижняя панель на мобильных.

Свойства:

- тот же синий градиент, что у сайдбара;
- логотип;
- кнопка звонка;
- кнопка меню;
- высокий `z-index`;
- безопасный нижний отступ с учетом мобильных браузеров.

### Buttons

Базовая кнопка:

```css
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-height: 48px;
  border-radius: 999px;
  padding: 14px 20px;
  font-family: var(--font-body);
  font-weight: 800;
  letter-spacing: 0.07em;
  text-transform: uppercase;
  transition: transform 0.2s ease, box-shadow 0.2s ease, background 0.2s ease;
}
```

Primary:

- белый текст;
- синий градиент;
- акцентная тень.

Secondary:

- белый или прозрачный фон;
- тонкая граница;
- темный текст;
- используется для вторичных действий.

Sidebar booking:

- белая кнопка на синем фоне;
- темный текст;
- на hover становится синей/акцентной.

### Cards

Карточки используются для повторяемых элементов:

- услуги;
- цены;
- отзывы;
- команда;
- оборудование;
- новости;
- контакты;
- элементы админки.

Правила:

- не вкладывать карточки в карточки;
- радиус умеренный, чаще `18-28px` для текущего визуала;
- у карточек должна быть четкая роль, не декоративная рамка вокруг каждой секции;
- медиа в карточке должно иметь стабильное соотношение сторон.

### Media Cards

Для фото/видео:

- крупные изображения;
- `object-fit: cover`;
- стабильный `aspect-ratio`;
- не использовать темные блюры, если пользователь должен рассмотреть студию;
- alt-тексты должны быть заполнены для реальных изображений.

### Forms

Формы должны быть простыми и контрастными.

Поля:

- высота не меньше `48px`;
- мягкая светлая заливка;
- видимый focus state;
- ошибки рядом с полем или под формой;
- текст ошибки не должен ломать layout.

В CRM-сценарии собственная форма записи не является основным интерфейсом. Кнопки записи открывают внешний CRM-виджет.

## Анимации и движение

### Общий принцип

Движение должно создавать ощущение студийного света и живого пространства, но не мешать чтению.

Используются:

- плавное появление секций;
- hover-подъем карточек и кнопок;
- spotlight, реагирующий на курсор;
- синий градиентный flow в сайдбаре и mobile dock;
- бегущая строка;
- плавное открытие модалок/lightbox.

### Timing

```css
:root {
  --ease-standard: cubic-bezier(0.2, 0.7, 0.2, 1);
  --duration-fast: 0.18s;
  --duration-base: 0.28s;
  --duration-slow: 0.42s;
}
```

### Reduced motion

Для `prefers-reduced-motion: reduce`:

- отключить бесконечные декоративные анимации;
- оставить мгновенные или короткие переходы состояний;
- не двигать большие области экрана.

На мобильных тяжелые эффекты должны быть отключены или сильно упрощены.

## Иконки

Иконки должны быть простыми, одноцветными и читаемыми.

Текущий проект использует inline SVG-иконки в `app.js`. В Nuxt лучше вынести их в компонент:

- `BaseIcon`;
- словарь иконок;
- единый размер;
- единый stroke/fill behavior.

Для новых UI-кнопок предпочтительно использовать знакомые пиктограммы, а не текстовые прямоугольники.

## SEO и контент

SEO-тексты, заголовки страниц, описания, OG-image и ключевые секционные тексты управляются контентом.

Визуальные правила для контента:

- длинные абзацы ограничивать по ширине;
- списки услуг держать сканируемыми;
- цены выделять крупно;
- контакты делать крупными и кликабельными;
- фото студии показывать достаточно большими.

## Админка

Админка должна быть визуально спокойнее публичного сайта.

Правила:

- больше плотности;
- меньше декоративных анимаций;
- четкие вкладки;
- понятные формы;
- стабильные размеры полей;
- явные статусы сохранения;
- опасные действия отделять визуально.

Админка может использовать тот же акцентный синий, но не должна повторять всю театральность публичной части.

## Чеклист качества

Перед сдачей страницы:

- заголовки не вылезают из контейнеров;
- кнопки не ломаются на мобильных;
- меню не перекрывает основной сценарий;
- CTA записи всегда доступен;
- фото студии видны и не превращены в темный фон;
- анимации не мешают чтению;
- интерфейс читается на desktop и mobile;
- CRM-виджет открывается по кнопке записи;
- цвета соответствуют палитре;
- шрифты подключены и не скачут при загрузке.
