# Что нужно предоставить и куда добавлять файлы

Этот файл нужен, чтобы собрать все материалы в одном порядке и не потерять ничего важного.

## 1. Что нужно от клиента

### Брендинг

- логотип в SVG
- логотип в PNG на прозрачном фоне
- версия логотипа для тёмного фона
- версия логотипа для светлого фона
- если есть — знак/иконка отдельно

### Фото и видео

- фото интерьера студии
- фото оборудования
- фото команды
- фото для главного экрана
- видео-фон для hero-блока, если есть
- видео примеров работ / кейсов

### Тексты

- описание студии
- список услуг
- цены или пакеты
- FAQ
- контакты
- адрес
- ссылки на соцсети

### Для бронирования

- список услуг с длительностью
- рабочие часы
- выходные дни
- правила бронирования
- контакт для подтверждения

### Шрифты и брендовые настройки

- шрифт для заголовков и меню уже предусмотрен в проекте: `fonts/TTFirs-Black.woff2`
- основной текст будет использовать `Inter` из Google Fonts
- основной синий цвет интерфейса: `#0069fe`

## 2. Куда добавлять файлы

Ниже — рекомендуемая структура для будущего проекта.

```text
fonts/
  TTFirs-Black.woff2

public/
  brand/
    logo.svg

    logo-black.svg
    logo-mark.svg

  media/

  og/

uploads/

```

## 3. Что куда класть

### Логотипы

- `public/brand/logo.svg` — основной логотип
- `public/brand/logo-white.svg` — логотип для тёмного фона
- `public/brand/logo-black.svg` — логотип для светлого фона
- `public/brand/logo-mark.svg` — сокращённый знак

### Шрифты

- `fonts/TTFirs-Black.woff2` — шрифт для заголовков, меню и акцентных элементов

### Фото

- `public/media/photos/hero/` — крупные изображения для первого экрана
- `public/media/photos/studio/` — фото студии и интерьера
- `public/media/photos/team/` — фото команды
- `public/media/photos/services/` — фото по услугам
- `public/media/photos/cases/` — фото кейсов и портфолио

### Видео

- `public/media/videos/hero/` — фоновые и промо-видео для главного экрана
- `public/media/videos/cases/` — видео-примеры работ
- `public/media/videos/reels/` — короткие ролики и нарезки

### Обложки

- `public/media/covers/hero/` — превью для видео hero-блока
- `public/media/covers/cases/` — превью кейсов

### Иконки

- `public/icons/` — favicon и системные иконки

### Open Graph

- `public/og/` — изображения для предпросмотра ссылок в соцсетях и мессенджерах

## 4. Правила подготовки файлов

- фото в хорошем разрешении, без сильного сжатия
- видео в максимально чистом качестве
- логотипы лучше отдавать в векторе
- названия файлов делать латиницей, без пробелов
- лучше использовать понятные имена: `hero-01.jpg`, `studio-main-01.jpg`, `logo-white.svg`

## 5. Что желательно прислать сразу

- всё, что есть по логотипам
- 10–20 лучших фото студии
- 3–5 видеофрагментов
- список услуг и цен
- контакты и соцсети
