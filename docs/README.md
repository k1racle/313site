## Кратко о проекте

Сайт для студии подкастов, звукозаписи и видеосъёмок «СТУДИЯ 313».

Ключевая идея:

- премиальный визуальный стиль
- крупная типографика
- горизонтальное листание секций на десктопе
- плавные переходы без полной перезагрузки страниц
- встроенная админка и система заявок/бронирования
